# TRUYEN CRAWLER DATA 

## 📋 Tổng quan

File `TruyenDataCrawlerUnified.js` là file gộp duy nhất chứa tất cả các function crawl truyện, thay thế cho các file riêng biệt:

- ❌ `TruyenHotData.js`
- ❌ `TruyenKiemHiepData.js` 
- ❌ `TruyenTienHiepData.js`
- ❌ `TruyenMoiCapNhatData.js`
- ❌ `TruyenDataCrawler.js`

## ✅ Lợi ích của việc gộp file

1. **Quản lý tập trung**: Chỉ cần sửa 1 file thay vì 5 file
2. **Không trùng lặp code**: Logic crawl chung, không duplicate
3. **Dễ bảo trì**: Sửa lỗi, thêm tính năng ở 1 chỗ
4. **Import đơn giản**: Chỉ cần require 1 file
5. **Tính nhất quán**: Tất cả function có cùng cấu trúc

## 🚀 Cách sử dụng

### Import file gộp

```javascript
// Thay vì import từng file riêng biệt
const { CrawlTruyenHot } = require('./TruyenHotData');
const { CrawlTruyenKiemHiep } = require('./TruyenKiemHiepData');

// Chỉ cần import từ file gộp
const {
    CrawlTruyenHot,
    CrawlTruyenKiemHiep,
    CrawlTruyenTienHiep,
    CrawlTruyenMoiCapNhat,
    // ... và tất cả thể loại khác
} = require('./TruyenDataCrawlerUnified');
```

### Sử dụng các function

#### 1. Crawl cơ bản (danh sách truyện)

```javascript
// Crawl truyện hot
const hotData = await CrawlTruyenHot();

// Crawl truyện kiếm hiệp
const kiemHiepData = await CrawlTruyenKiemHiep();

// Crawl truyện tiên hiệp
const tienHiepData = await CrawlTruyenTienHiep();

// Crawl truyện mới cập nhật
const moiCapNhatData = await CrawlTruyenMoiCapNhat();
```

#### 2. Crawl với nội dung chi tiết

```javascript
// Crawl truyện hot + nội dung chi tiết
const hotWithContent = await CrawlTruyenHotWithContent();

// Crawl truyện kiếm hiệp + nội dung chi tiết
const kiemHiepWithContent = await CrawlTruyenKiemHiepWithContent();
```

#### 3. Crawl nội dung đơn lẻ

```javascript
// Crawl nội dung của 1 truyện cụ thể
const content = await CrawlTruyenContent('/truyen/abc');
```

#### 4. Utility functions

```javascript
// Lấy danh sách tất cả thể loại
const allTypes = getAllTruyenTypes(); // 40 thể loại

// Crawl tất cả thể loại cùng lúc
const allResults = await CrawlAllTruyenTypes(false); // false = không có nội dung chi tiết
const allResultsWithContent = await CrawlAllTruyenTypes(true); // true = có nội dung chi tiết
```
